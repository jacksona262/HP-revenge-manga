HP: REVENGE — Character Design Consistency Bible
This is the official visual rulebook we'll use when producing the manga.
1. Core art direction
￼



Character artwork
Grounded delinquent manga aesthetic. Recognizable faces, distinctive hairstyles, realistic teenage proportions, expressive eyes, and sharp silhouettes. Characters should look like teenagers, not bodybuilders in their thirties.
￼



Inking and shading
Strong blacks, controlled screentones, expressive facial shadows, detailed environments, and occasional heavy contrast for intimidating moments. No random shifts between cartoon, photorealistic, and painterly styles.
2. Non-negotiable consistency rules
Facial identity: Fixed eye shape, nose, jawline, eyebrows, ears, and facial proportions for every character.  
Hair: Fixed base hairstyle, hairline, length, texture, and color. Wind and movement can affect it, but it must remain recognizable.  
Height: Canonical heights remain consistent. Ren is always 6'5" and the tallest character. Jackson is 6'0"; Jack is 5'8".  
Build: Every character gets a defined frame, shoulder width, posture, and proportions. No unexplained muscle or height changes.  
Clothing: Each gang has a standardized uniform, insignia, and color identity. Individual customization is tracked.  
Age: Characters must look age-appropriate, including younger members such as Jason Schmidt.  
Expressions: Characters have recognizable resting expressions and distinctive ways of showing anger, embarrassment, excitement, or fear.  
Continuity: Clothing damage, accessories, and other temporary changes persist logically between scenes.  
Black-and-white readability: Characters must be identifiable without relying on hair color alone.  
Reference-first production: No final panel is approved unless it matches that character's locked reference sheet.  
3. Character reference sheet standard
Every named character will eventually receive one master sheet containing:
Full-body front
Full-body side
Full-body back
Face close-up
Six expressions
Three signature poses
Required views for each master character reference sheet.
Each sheet will also specify exact colors for covers, grayscale hair values for manga panels, height, body proportions, outfit details, and distinguishing features.
4. Design priority
We'll build and lock designs in this order: Jackson → Jack → Bryson → Isaac → Ren → Kai → Marcus, followed by each gang's second-in-command and supporting cast.
The most important production rule is that we create one canonical reference for each character and reuse it throughout the entire manga, rather than independently redesigning characters for every illustration.
